## Projects

All projects below support [CrossingWatersNetwork.org](https://crossingwatersnetwork.org), a nationwide directory of 13,745 mental health treatment facility listings across all 50 states. These repos are simplified public versions that show the design and results. Full versions are available to walk through on request.

| Project | What it shows |
|---|---|
| [cwn-content-automation](https://github.com/bertmonestine/cwn-content-automation) | An automated blog and social publishing pipeline: n8n schedule, Python, Claude API, WordPress and Buffer |
| [cwn-data-pipeline](https://github.com/bertmonestine/cwn-data-pipeline) | A Python data-cleaning pipeline that turns public SAMHSA data into 13,745 import-ready listings |
| [cwn-analytics-tracking](https://github.com/bertmonestine/cwn-analytics-tracking) | GA4 and Google Tag Manager event tracking with a Data Studio performance dashboard |
| [cwn-market-prioritization-sql](https://github.com/bertmonestine/cwn-market-prioritization-sql) | A SQL analysis that ranks states by coverage gaps, combining listings, GA4 traffic and Census population, to guide market prioritization and budget allocation |
